# Northstar Cloud Systems Vendor Profile

Northstar Cloud Systems provides managed document automation and analytics for mid-market enterprises. The company states that it has operated for more than eight years and offers United States data hosting.

Security documentation supplied for review includes a current SOC 2 Type II report, an incident response plan, and a data processing agreement. The agreement includes data protection commitments and a list of subprocessors. Northstar states that it will provide breach notification within 24 hours of confirming a security incident.

Northstar supplied a certificate of cyber insurance and commercial liability insurance. The vendor also provided a business continuity plan and states that its disaster recovery program is tested annually.

The proposed service level agreement commits to 99.95 percent monthly uptime. Priority-one incidents receive a 30-minute response target, 24-by-7 support, a named support team, and executive escalation. The disaster recovery plan states an RTO of four hours and an RPO of one hour.

The contract draft provides data export, transition support, termination assistance, and an exit plan. Financial stability documentation includes a management-prepared financial statement and a statement that no going-concern issue has been identified.
