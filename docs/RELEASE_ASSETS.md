# v3.0.0 GitHub Release Assets

Upload the following files to the `v3.0.0` GitHub Release rather than committing them to the main branch:

- `EACC_v3.0.0_Source.zip` — final GitHub-ready source snapshot.
- `EACC_v3.0.0_Verified_Evidence.zip` — sanitized verification JSON, self-test report, test logs, hygiene scan, screenshots, manifest, and checksums.
- `EACC_Phase3_Demo_v3.0.0.mp4` — refreshed demonstration showing the final 11-agent / 5-tool interface.
- `SHA256SUMS.txt` — checksums for all release assets.
- `RELEASE_NOTES_v3.0.0.md` — release summary, supported runtime, known boundaries, and evaluator launch sequence.

Do not place local databases, uploaded documents, `.env` files, secret material, or unsanitized machine logs in the release.
