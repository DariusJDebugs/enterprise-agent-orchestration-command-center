# 2–4 Minute Evaluator Demo Script

**0:00–0:20 — Project origin.** Explain that the published solution requirements governed the workflow, while the vendor-risk use case was independently selected as the demonstration vehicle.

**0:20–0:40 — Command overview.** Show 11 governed agents, 5 registered tools, healthy runtime, and persistent mission history.

**0:40–1:00 — Knowledge boundary.** Load demonstration data and show internal policies indexed with stable citations and security status.

**1:00–1:35 — Orchestration.** Launch the Northstar review. Show coordinator decomposition, parallel specialists, reviewer, draft report, red team, and final report.

**1:35–1:55 — Evidence.** Open messages, tool calls, observability, audit, and final report. Point out traces, latency/token/cost metrics, citations, and valid audit chain.

**1:55–2:25 — Governance.** Run the prompt-injection proof. Show `prompt_injection_blocked`, `critical`, `quarantine_and_exclude_from_rag`, and exclusion from ordinary RAG.

**2:25–2:45 — Additional controls.** Show human approval, unauthorized-tool denial, retry recovery, weak-report repair, budget stop, and operator controls.

**2:45–3:00 — Delivery evidence.** Show readiness, schema version 3, hardened deployment files, test results, and the requirements-to-evidence matrix.
